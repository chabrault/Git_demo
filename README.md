# Lessons from the Jan 28 meetings

- Need to add collaborators even in public project to allow them to make edits
- Synchronize the Github repository with Github desktop or another software. Downloading a file does not connect your computer to the repository
- Pull before making any change
- Push changes in two steps: make a commit (don't forget the commit summary) and push
![github desktop commit and push](<Screenshot 2025-04-02 185924.png>)

- If unsynchronized changes has been made to the repository, you won't be able to push your changes. You'll need to merge branches.
- Text files, including .csv, .md, .R, .txt, etc can be used to track changes, whereas .xlsx, .pdf, .png can't.
